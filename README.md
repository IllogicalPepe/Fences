# FenceDesk

Windows desktop fence organizer (64-bit).

## Download

Download **FenceDesk-2.0.0-win-x64.zip** from this repo.

## Install

1. Unzip the file completely (Extract All)
2. Open the folder `FenceDesk-2.0.0-win-x64`
3. Double-click **Install.bat** (or run **FenceDesk.exe** for portable mode)
4. If SmartScreen appears: More info → Run anyway
5. Look for the FenceDesk tray icon near the clock

See HOW-TO-INSTALL.txt inside the zip for more.
