## FenceDesk 2.1.3

Desktop fence organizer for Windows (WPF).

### Install
Download **[FenceDesk-Setup-2.1.3.exe](https://github.com/IllogicalPepe/Fences/releases/latest/download/FenceDesk-Setup-2.1.3.exe)** and run it (no admin required).

### What's new
- Double-click empty wallpaper to hide/show fences; desktop icons are hit-tested so opening a file no longer toggles fences
- **Black hole delete** — deleting or removing an icon swirls an accretion disk around it, then swallows the tile
- Works on Delete/Backspace, **Remove from fence**, and portal **Delete from folder…**
- Multi-select staggers a hole on each icon

### Uninstall
Settings → Apps, or Start Menu → FenceDesk → Uninstall
